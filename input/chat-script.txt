# 聊天剧本 · 按歌词逐句
#
# 格式：  <谁> <模式> <气泡> @<歌词句号>[+延迟] <文本>
#
# ── 谁 ────────────────────────────────────────────────
#   you = 僕（用户 / 人类，想放弃的人）
#   ai  = 君（AI，冷淡、系统化、是台模板机器）
#
# ── 模式（不只是「发消息」）────────────────────────────
#   send     发送
#   hold     打好了但**不发**，文字停在输入框
#   del      打了又删掉（说不出口）
#   bs       按退格但文字**不消失**
#   retract  AI 回复后又撤回
#   upload   上传图片
#   sky      聊天区出现蓝天/正午/窗帘的画面
#   none     什么都不做，只剩光标
#
# ── 气泡 ──────────────────────────────────────────────
#   n 普通 / s 小 / t 极小 / g 灰色 / w 暖灰（全片唯一暖色）
#
# ── 说明 ──────────────────────────────────────────────
#   @16 表示钉在第 16 句歌词的起音时间上；@16+1.1 表示再晚 1.1 秒。
#   时间只用句号引用，不写死秒数 —— 换音源重打歌词时这份剧本不用改。
