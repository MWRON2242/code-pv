# 02 剪辑术语与代码术语对照表

用剪辑的行话理解代码里的每个部件。这张表是整库的「翻译器」。

## 时间线相关

| 剪辑里的说法 | 代码渲染里对应 | 解释 |
|---|---|---|
| 时间线 / 主轨道 | 歌曲时间轴 `t` | 全片唯一的主时间线，通常就是那首歌 |
| 打点表 / 卡点表 | markers 数据（JSON） | 全片所有切换的依据，见 [[03 打点表 - 全片的地基]] |
| 帧率 | `fps` 变量 | 24 / 25 / 30 / 60 |
| 时间码 | `frame / fps` | 帧号 ÷ 帧率 = 秒 |
| 逐字歌词字幕 | 逐词时间数据 | 每句/每个字的起止时间 |
| 分镜表 / 剪辑脚本 | 镜头列表（代码里的数组） | 「第几秒到第几秒画什么」 |

## 图层与合成相关

| 剪辑里的说法 | 代码渲染里对应 | 解释 |
|---|---|---|
| 图层 / 轨道 | 组件的叠加顺序 | 后面的盖住前面的 |
| 蒙版 / 画中画的入出点 | 时段控制表 | 哪几段由哪个图层接管画面 |
| 谁是主画面 / 背景调暗 | 主次表 + 不透明度 | 参考工程里非主角一侧降到 42% 亮度 |
| **预合成替换 / 替换素材** | 运行时替换函数 | **精髓**：不改素材本身，只在合成时换掉某一层，已做好的动效全部保留 |
| 调整图层 | 补丁（patch） | 审片意见不改原文件，而是叠加一层修正 |
| 调色 / 特效 | 后期处理函数 | 辉光、残影、扫描线…… |
| 嵌套合成 | 子组件 | 一个合成里放另一个合成 |

## 工程管理相关

| 剪辑里的说法 | 代码渲染里对应 | 解释 |
|---|---|---|
| 工程文件 | 代码仓库 | 但它是纯文本，可以用 git 管版本 |
| **相对路径 / 媒体离线** | 目录名写死在代码里 | 改目录名 → 代码找不到文件 → 全红 |
| 母版 / 导出预设 | 渲染参数 | 先出无损母版，再转码 |
| 代理 / 低分辨率预览 | 预览模式 / 降采样 | 加快预览速度 |
| 参考片 / 比对版 | 基准截图 + 数值比对 | 验证「我重出的这版差多少」 |
| 工程打包 | `npm install` / 依赖清单 | 记录用到哪些库 |

## 术语陷阱

> [!warning] 「模板」是个陷阱词
> 剪辑圈说的「模板」= 内容被做成了变量，换字换图就出片。
> 代码渲染的工程通常**不是模板**，是**参考实现**。区别见 [[07 为什么参考工程不是模板]]。

> [!note] 「渲染」在两个圈子里意思不同
> 剪辑：把时间线导出成文件。
> 代码渲染：**生成每一帧的画面**（可能只是中间产物），再编码成文件。两步是分开的。
