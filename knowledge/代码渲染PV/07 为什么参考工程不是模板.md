# 07 为什么参考工程不是模板

拿别人的开源工程改造成自己的片子，这个念头每个人都会有。**结论：技术上导得出，成品没意义，法律上也发不了。**

但它的手法非常值得学。区别在这里：

| | 模板 | 参考实现 |
|---|---|---|
| 内容 | 被做成了**变量** | 是写死的**常量** |
| 换素材 | 换字换图就出片 | 画面能播，但卡点全错、字幕时间全错、分镜在讲另一个故事 |
| 你得到什么 | 一支成品 | **一套手法** |

## 三堵墙

### 第一堵：媒体离线（技术墙，能绕）

换立绘、换字体、换舞者画面——这就是**替换素材**，而且作者故意留了口子（放进同格式的文件就自动跳过替身生成）。这部分可以换。

### 第二堵：分镜是写给那首歌的（结构墙，绕不过）

关键区别：

> 它**不是**「配着 BGM 剪的画面」，而是**按这首歌每一个字算出来的画面**。

所以换歌 ≈ **换掉一支按口型逐帧做的动画的配音**：口型全废。

换歌等于同时换掉：

- 打点表（逐词时间）
- 逐字字幕时间
- 分镜表（96 个镜头）
- 每一个转场
- 窗口里写死的每一句台词

而且叙事内容是死的：开机、问你「你是谁」、RLHF 的赞踩、EXECUTION、鲸落——**全部照着原歌词写**。换首歌，画面还在动，但它在讲另一个故事。

顺带一个硬约束：**参考工程的目录名不能改**，因为代码靠相对位置互相查找。想「重命名一遍变成自己的项目」直接堵死（见 [[04 图层与合成 - 替换素材不丢动效]]）。

### 第三堵：素材授权（最硬）

- 音乐：版权方保留，只按官方指引允许个人非商业二创
- 歌词：版权独立
- 美术：CC BY-NC-SA（禁商用 + 同协议）
- 字体：部分不可再分发
- 原片舞者：**作者自己都没拿到完整授权**，才不得不用替身

换掉音乐和美术之后，你会发现**真正属于你的只剩代码**。详见 [[06 许可与素材授权]]。

## 那它到底该怎么用

**抄这四件事：**

1. **纯函数范式**：每帧 = `f(t)`，无剪辑软件、无手工关键帧
2. **运行时替换函数**（预合成替换）：不改引擎源文件，只在合成时换掉某一层，动效全保留
3. **补丁链式审片**：每轮审片一个补丁叠加，而不是回头改原始脚本
4. **分阶段可重跑的流水线**：检查 → 歌词 → 素材 → 截图 → 渲染，每段能单独跑

**真正能整条拿走的只有一半**：「逐帧生成画面 → 出序列帧 → 合成」这条流程。流程能复用，**道具和脚本得是你自己的**。

## 一句话

> [!important] 把它当 asset 模板用会走进死胡同；把它当 timeline + 架构的参考实现用，非常值。
