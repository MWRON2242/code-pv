# 代码渲染 PV · 索引

一支用**代码**逐帧渲染出来的音乐 PV。不是用剪辑软件剪，而是写规则让电脑把每一帧算出来。

> [!tip] 一句话抓住本质
> **每一帧都是歌曲时间 `t` 的函数。**
> 剪辑是「把拍好的素材摆到时间线上」；代码渲染是「给一个时间点，算出那一刻的画面」。

## 学习路径建议

1. 先读 [[01 核心概念 - 时间是一等公民]]，建立心智模型
2. 再读 [[02 剪辑术语与代码术语对照表]]，把已有知识挂上去
3. 然后动手做 [[03 打点表 - 全片的地基]]，这是唯一必须先做对的事
4. 其余按需查

## 关键结论备忘

- 代码出片**不等于**一个完整 Python 程序；语言和框架都是可换的
- 真正的门槛是「把时间轴写进代码」，不是「用 Python」
- 参考工程的价值是**手法**，不是**素材**
- 素材授权里最容易翻车的是**字体**和**音乐**
