# 06 许可与素材授权

## 核心认知：成品是四层独立的权利

代码出片 = **代码 + 画面 + 音乐 + 字体**。这四层的授权**互不影响**：

- 代码是 MIT，**不代表**画面能用
- 画面是你自己做的，**不代表**背景音乐能用
- 音乐有授权，**不代表**字体可以随片分发

> [!example] 参考工程就是活例子
> - 代码：MIT ✅
> - 美术（立绘/表情）：CC BY-NC-SA 4.0（禁商用 + 同协议共享）
> - 音乐与歌词：版权保留，**不适用 MIT**，只按版权方的二创指引
> - 字体：部分 Windows 字体**不可再分发**
> - 原片舞者画面：**因为第三方模型/动作授权未确认，作者不得不用替身**
>
> 一个 MIT 仓库里，只有它自己的代码可以随便用。

## 各层的常见条款

| 协议 | 能用吗 | 必须做什么 |
|---|---|---|
| MIT / Apache | ✅ 含商用 | 保留版权声明 |
| CC BY | ✅ 含商用 | 署名 |
| CC BY-SA | ✅ 含商用 | 署名 + **改编部分同协议** |
| CC BY-NC | ❌ 不可商用 | 署名 |
| CC BY-NC-SA | ❌ 不可商用 | 署名 + 同协议 + 注明改动 |
| CC0 / 公共领域 | ✅ | 无 |
| 版权保留 | 看具体指引 | 通常需授权 |

## 项目里的落地方式

见工程根目录的 `ASSETS.md`——一张登记表，逐项记录：

`素材 | 来源/作者 | 协议 | 可商用 | 需署名 | 需同协议 | 链接凭证`

出片前逐条核对，避免项目做大了忘记。

## 常见坑

1. **「非商用」≠「随便用」**：CC BY-NC-SA 还附带署名和同协议，改编部分也得同协议。
2. **字体最容易翻车**：系统自带的商业字体不可再分发，别打进工程包。
3. **代理/中间产物也算分发**：开源工程前先配好忽略规则，别把不该传的素材传上去。
4. **参考实现 ≠ 可直接取用**：它的代码可用，美术/音乐/歌词不能顺带拿走。
5. **AI 生成内容要标注**：多数平台和版权方都要求明确声明。
6. **「代码渲染」不是免死金牌**：不能宣称「全部画面均非 AI」如果画面里有 AI 素材。
