# 08 工具谱系

按 [[05 四个层级 - 代码覆盖到哪一层]] 的层级归类。

## 层级 2：声明式场景描述（**推荐从这里开始**）

| 工具 | 语言 | 许可 | 特点 |
|---|---|---|---|
| **Remotion** | TypeScript / React | 个人及 ≤3 人公司免费，更大需商业授权 | 自带 ffmpeg 和 Chromium，**零额外安装**；浏览器实时预览，可拖时间轴；文档示例最多 |
| **Motion Canvas** | TypeScript | **MIT** | 完全宽松的许可；自带时间轴预览；生态和教程较少；导出需要系统里有 ffmpeg |
| **Manim** | Python | MIT | 数学动画取向，3Blue1Brown 那套；做公式推导极强，做音乐 PV 偏重 |
| **p5.js** | JavaScript | LGPL | 创意编程入门首选；适合生成艺术风格 |

## 层级 3：自建引擎 / 底层绘制

| 工具 | 语言 | 适用 |
|---|---|---|
| Pillow (PIL) | Python | 逐像素/逐字符绘制；参考工程用的就是它 |
| MoviePy | Python | 视频合成胶水 |
| Three.js / WebGL | JS | 3D、着色器效果 |
| GLSL / Shadertoy | 着色器 | 纯 GPU 画面，适合抽象视觉 |
| openFrameworks / Cinder | C++ | 高性能实时 |
| nannou | Rust | 创意编程 |
| Blender (bpy / Geometry Nodes) | Python | 3D 场景渲染 |

## 层级 4：实时 / 不可精确复现

| 工具 | 说明 |
|---|---|
| TouchDesigner | 节点式实时视觉，VJ 常用 |
| Notch | 实时图形 |
| Hydra / Live Coding | 现场编码演出 |

**不适合做要发布的成片**——同一秒不会出现第二次。

## 辅助工具

| 用途 | 工具 |
|---|---|
| 编码 / 转码 | ffmpeg |
| 逐帧截图 | Playwright、Puppeteer |
| 逐词对齐 | LRCLIB（行级）、Whisper 系（逐词）、强制对齐工具 |
| 节拍检测 | librosa（Python）、essentia.js（JS/WASM） |
| 音频分析 | Sonic Visualiser、Audacity |
| 打点 | 本项目 `tools/tapper` |

## 怎么选

> [!tip] 决策顺序
> 1. 先问「我需要完全自定义的质感吗？」
> 2. 不需要 → 层级 2，**优先 Remotion**（省掉装 ffmpeg 的麻烦）
> 3. 在意许可宽松度 → Motion Canvas（MIT）
> 4. 需要 3D → Three.js 或 Blender
> 5. 需要逐字符/像素级控制 → 层级 3 手写
> 6. **永远不要一上来就写引擎**
