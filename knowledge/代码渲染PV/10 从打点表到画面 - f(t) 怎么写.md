# 10 从打点表到画面 - f(t) 怎么写

有了打点表，怎么写「画面」这部分的代码？这是最核心的手艺。

## 三个入口

| 你要什么 | 用什么 | 说明 |
|---|---|---|
| 现在是第几帧 | `useCurrentFrame()` | 帧号，除以 fps 就是秒 |
| 画布信息 | `useVideoConfig()` | `fps` / `width` / `height` / 总帧数 |
| 放音频 | `<Audio src={staticFile('...')} />` | 音频要放在 `public/` 里 |

```tsx
const frame = useCurrentFrame();
const { fps } = useVideoConfig();
const t = frame / fps;          // 秒
```

> [!important] 只依赖 frame
> 组件里**不能**有状态、定时器、`Date.now()`、`Math.random()`。
> 同一个 frame 必须永远算出同一个画面，否则渲染会错帧。

## 模式 1：查表（把打点表变成画面）

```ts
// 当前落在第几拍
let idx = -1;
for (let i = 0; i < beats.length; i++) if (t >= beats[i]) idx = i;
```

拿到 `idx` 之后，一切都能算：第几小节、歌词唱到哪、日志该打印几行。

## 模式 2：衰减（音乐视觉的灵魂）

**「击打瞬间亮一下，然后衰减」** —— 几乎所有跟着音乐抖的效果都是这个：

```ts
const since = t - beats[idx];        // 距离上一拍多久
const flash = Math.max(0, 1 - since / 0.22);   // 1 → 0
```

把这个 `flash` 用到亮度、缩放、发光、位移上，就是"卡点"。

- 想让抖动更"脆"→ 把 `0.22` 改小
- 想让它"拖尾"→ 改大，或用 `Math.exp(-since * k)`

## 模式 3：确定性伪随机

需要"随机感"但又必须可复现时，用固定种子的伪随机：

```ts
export function prng(n: number): number {
  let s = (Math.floor(n) * 1664525 + 1013904223) >>> 0;
  s = (s * 1664525 + 1013904223) >>> 0;
  return s / 4294967296;
}
```

**同一个 n 永远得到同一个数。** 频谱条、字符云、噪声纹理全靠它。

用 `Math.random()` 会怎样？渲染时每一帧都可能不一样，而且 Remotion 会并行渲染不同帧——
画面会闪、会跳、无法复现。

## 模式 4：过渡

帧驱动而不是时间驱动：

```ts
const appear = Math.max(0, Math.min(1, age / 0.3));   // 0→1 淡入
style={{ opacity: appear, transform: `translateY(${(1 - appear) * 12}px)` }}
```

## 完整的最小例子

```tsx
export const MyScene: React.FC = () => {
  const frame = useCurrentFrame();
  const { fps, width, height } = useVideoConfig();
  const t = frame / fps;

  const idx = beatIndexAt(t);
  const f = flash(t);

  return (
    <AbsoluteFill style={{ backgroundColor: '#0d1117' }}>
      <Audio src={staticFile('audio/song.wav')} />
      <div style={{
        position: 'absolute',
        left: `${(t / total) * 100}%`,          // 播放头随时间移动
        top: 0, width: 3, height: '100%',
        backgroundColor: '#f0f6fc',
      }} />
      <div style={{
        position: 'absolute', left: '50%', top: '50%',
        width: 100 + f * 140, height: 100 + f * 140,   // 跟着拍胀缩
        marginLeft: -(100 + f * 140) / 2,
        marginTop: -(100 + f * 140) / 2,
        borderRadius: '50%',
        backgroundColor: `rgba(31,111,235,${0.1 + f * 0.5})`,
      }} />
    </AbsoluteFill>
  );
};
```

## 组织方式：一个镜头一个组件

- `src/lib/beats.ts` —— 共用的取数逻辑（所有镜头都 import 它）
- 一个镜头 / 一个风格 = 一个 `.tsx` 组件
- `src/Root.tsx` —— 「影片登记处」，把每个组件登记成一条可渲染的成片

**好处**：换风格只改组件，时间轴和数据一行都不用动。本项目的四个方向预览
就是同一套数据配四套组件，验证了这一点。
